### 关键设计

#### 买入信号规则（必须同时满足）
1. 游资席位净买入 ≥ 500万 且 占比 ≥ 1.5%
2. 连板天数 ≥ 2 且 晋级率 ≥ 30%
3. 涨停数 ≥ 50 且 情绪指数 ≥ 60
4. 流通市值 50亿~500亿，换手率 ≥ 5%

#### 卖出信号规则（满足任一）
- 止损：回撤 ≥ 8%
- 止盈：收益 ≥ 30%
- 时间止损：持仓超5日且未盈利
- 形态止损：炸板
- 游资撤退：龙虎榜卖方大额净卖出

#### 状态机设计
```
PENDING_BUY → HOLDING → PENDING_SELL → CLOSED
    ↓            ↓            ↓
CANCELLED   STOP_LOSS    CANCELLED
```

#### 风控红线（硬编码，不可覆盖）
- 最多同时持有5只
- 单只不超过总资产40%
- 单日组合亏损>5%停止新开仓
- 组合回撤>20%全部平仓

### 验收标准

- [ ] 信号引擎输出可重现
- [ ] 状态机覆盖率100%
- [ ] 风控红线不可被绕过
- [ ] 2023年回测年化收益为正
- [ ] 回测报告无NaN字段
- [ ] 所有单元测试通过
