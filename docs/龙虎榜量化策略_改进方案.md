# 龙虎榜量化投资策略——完整改进方案

> 本方案基于原有龙虎榜净买入策略的评估结果，针对回测严谨性、因子有效性、过拟合防控、风控体系、工程落地五大维度进行系统性重构。全文不含完整代码实现，仅在必要处给出伪代码或函数签名提示。

---

## 第一部分：回测框架的根本性修复

### 1.1 消除未来信息泄露

**问题回顾：** 原方案中 `get_next_day_return` 函数通过 `df.iloc[1]` 获取"T+1日"数据，但在停牌、数据缺失、节假日等情况下，iloc[1] 可能对应的是 T+2 甚至更后面的交易日。此外，技术面打分函数的日期边界也未做严格限制。

**修复方案：**

建立一份完整的A股交易日历表（可从交易所官网或 AKShare 获取），所有日期索引操作必须基于交易日历而非自然日历。具体规则如下：

- T 日定义为龙虎榜公布日期（通常等于上榜交易日当天）。
- T+1 日必须通过交易日历查找"T 日之后的第一个交易日"，而非简单地取 DataFrame 的下一行。
- 若 T+1 日该股票停牌（开盘价为空或成交量为零），则该信号作废，不纳入回测统计。
- 技术面打分所使用的全部行情数据，截止日期必须严格等于 T 日收盘，不得包含 T+1 日任何数据。

**伪代码提示：**
```
next_trade_day = trade_calendar.get_next(trade_date)
if stock.is_suspended(next_trade_day):
    return None  # 信号作废
```

### 1.2 交易成本建模

**问题回顾：** 原方案的回测完全没有扣除交易摩擦成本，对于日内或隔日超短策略，这是致命缺陷。

**成本模型设计：**

| 成本项 | 数值 | 说明 |
|--------|------|------|
| 买入佣金 | 0.025% | 万2.5，多数券商水平 |
| 卖出佣金 | 0.025% | 万2.5 |
| 印花税 | 0.05% | 2023年8月28日后由千1降为千0.5，仅卖出收取 |
| 买入滑点 | 0.10% | 龙虎榜股票次日多为高开，竞价滑点显著 |
| 卖出滑点 | 0.05% | 卖出方向滑点相对较小 |
| **单次往返总成本** | **约0.25%** | 保守估计，实际可能更高 |

在回测框架中，每笔交易的实际收益率应按以下公式计算：

```
实际收益 = (卖出价 × (1 - 卖出佣金 - 印花税 - 卖出滑点))
         / (买入价 × (1 + 买入佣金 + 买入滑点))
         - 1
```

若策略的平均毛收益低于 0.3%，扣除成本后大概率为负，需要重新审视策略逻辑。

### 1.3 基准对比与统计检验

**问题回顾：** 原方案只报告了绝对收益指标，没有任何基准对比和显著性检验。

**基准设计：** 回测结果必须同时对比以下三个基准——

- **基准一：沪深300指数。** 代表大盘整体表现，用于衡量策略是否跑赢了"买入持有"。
- **基准二：中证1000指数。** 龙虎榜股票以中小盘为主，与中证1000比较更公平。
- **基准三：等权涨停股指数。** 即每天等权买入当天所有涨停的股票（不经过龙虎榜筛选），T+1 开盘买 T+1 收盘卖。这个基准衡量的是"龙虎榜筛选"本身是否提供了增量价值。

**统计检验要求：**

- 对策略超额收益（相对基准三）进行单样本 t 检验，p 值需低于 0.05 才可认为策略有效。
- 使用 Bootstrap 方法（至少 10,000 次重采样）构建收益率的 95% 置信区间。
- 计算信息比率（IR = 超额收益均值 / 超额收益标准差），IR 至少应大于 0.5。

### 1.4 止盈止损回测的精确化

**问题回顾：** 原方案用日K线的最高/最低价来判断止盈止损触发，但同一天内可能同时触及止损价和止盈价，日线无法判断先到哪个。

**修复方案分两个层次：**

**层次一（可行方案）：** 使用 5 分钟K线数据进行止盈止损模拟。数据来源可用 AKShare 的分钟级接口或通达信导出。在分钟级数据上按时间顺序逐根K线判断，第一个触发的条件即为实际出场点。

**层次二（简化但诚实的方案）：** 如果获取不到分钟数据，则在日线回测中对"同时触及止损止盈"的情况做保守假设——一律按止损处理。在回测报告中明确标注这一保守假设，并统计受此假设影响的交易笔数占比。

## 第二部分：因子体系重构

### 2.1 龙虎榜核心因子（原有因子改进）

#### 2.1.1 净买入额因子——归一化改进

原方案直接使用绝对净买入额排名，但不同市值的股票，同样的净买入额含义完全不同。5000 万净买入对一只 50 亿市值的股票是 1% 的流通盘，对 500 亿市值的股票只有 0.1%。

**改进方法：** 使用"净买入额 / 自由流通市值"作为标准化后的净买入强度因子。这个比值才能真正反映资金介入的力度。阈值建议设为 0.5% 以上（即净买入占流通市值的 0.5%）。

#### 2.1.2 席位质量因子——动态化

原方案中知名游资的营业部名单是硬编码的，但游资频繁更换席位。

**改进方法：**

- 建立营业部历史表现数据库。对每个营业部，统计其过去 6 个月内在龙虎榜买入后 T+1、T+3、T+5 的平均收益率和胜率。
- 每月自动更新一次排名，取过去半年胜率前 30 名的营业部作为"优质席位"名单。
- 不再依赖人工维护的"知名游资"字典，改为纯数据驱动的席位评分。

**营业部评分公式建议：**

```
席位得分 = 过去6个月胜率 × 0.4
         + 过去6个月平均T+1收益排名百分位 × 0.3
         + 过去6个月上榜次数的对数值 × 0.3（活跃度加分）
```

#### 2.1.3 机构席位因子——细分处理

原方案将所有"机构专用"席位等同对待，但机构席位中包含公募基金、私募基金、保险资管、QFII 等不同类型，它们的交易风格和后续股价表现差异很大。

**改进方法：**

- 多个机构席位同时出现在买方（≥2 个），信号强度显著高于单个机构买入。
- 机构在买方且卖方无机构 → 最强信号。
- 买卖双方都有机构 → 机构分歧信号，降低权重。
- 仅卖方有机构 → 负面信号，应排除。

### 2.2 新增高价值因子

以下是原方案完全缺失但对龙虎榜策略提升明显的因子：

#### 2.2.1 上榜原因分类因子

龙虎榜的上榜原因主要有三类：日涨幅偏离值达 7%、日振幅达 15%、日换手率达 20%。不同上榜原因对应的后续表现差异巨大。

| 上榜原因 | 含义 | 后续表现倾向 |
|----------|------|------------|
| 涨幅偏离 | 当天大涨（通常涨停或接近涨停） | 强势股延续，但高位接盘风险也大 |
| 振幅偏离 | 当天大幅波动（冲高回落或探底回升） | 分歧大，方向不确定 |
| 换手率偏离 | 当天换手异常高 | 可能是资金大幅换手，后续波动大 |

**建议处理方式：** 优先选择因"涨幅偏离"上榜且当天是涨停板的股票（即封板股），回避因"振幅偏离"上榜的股票（分歧过大）。换手率偏离上榜的需要结合净买入方向判断。

#### 2.2.2 买卖集中度不对称因子

这是龙虎榜数据中被严重低估的一个信号维度。

**定义：**

```
买入集中度 = 买方前5席位合计买入额 / 当日总成交额
卖出集中度 = 卖方前5席位合计卖出额 / 当日总成交额
集中度差值 = 买入集中度 - 卖出集中度
```

**逻辑：** 如果买方非常集中（少数几家大笔买入），而卖方非常分散（散户在卖），说明有明确的主力资金在收集筹码。反之，买方分散而卖方集中，可能是主力在有计划地出货。集中度差值越大，后续上涨概率越高。

#### 2.2.3 连续上榜频率因子

同一只股票如果在短时间内（如 5 个交易日内）多次出现在龙虎榜上，需要区分两种情况：

- **同方向连续净买入（2~3 次）：** 资金持续介入，趋势信号强，可加分。
- **高频交替出现（买卖反复上榜）：** 资金在做高抛低吸或对倒，信号嘈杂，应减分或排除。
- **单次首次上榜：** 中性信号，按其他因子正常评分。

#### 2.2.4 对倒行为检测因子

**定义：** 同一只股票的龙虎榜买方前5和卖方前5中，如果出现同一家营业部或已知的关联营业部（如同城同券商的不同营业部），则存在对倒嫌疑。

**处理方式：** 检测到对倒行为的股票，直接从候选池中剔除。对倒的净买入数据不反映真实的资金意图。

#### 2.2.5 北向资金验证因子

沪深港通的北向资金每日持仓变动数据可用于交叉验证龙虎榜信号。

**逻辑：** 如果龙虎榜显示大额净买入，同时北向资金在当天或前一天也在增持该股票，两个独立的资金信号互相印证，后续上涨的概率更高。反之，龙虎榜净买入但北向资金在减持，信号可信度下降。

**数据来源提示：** 可通过 `ak.stock_hsgt_individual_em()` 或同类接口获取个股北向资金流向。

### 2.3 技术面因子体系重建

#### 2.3.1 剔除低效因子

原方案中使用的 MACD 金叉和 RSI 指标，在 A 股短线交易中的预测能力已被大量研究证明非常微弱。建议将这两个因子从打分体系中移除，或大幅降低权重。

#### 2.3.2 替换为更有效的短线因子

| 因子名称 | 计算方式 | 逻辑 |
|----------|----------|------|
| **5日相对强弱** | 个股5日涨幅 - 所属行业5日涨幅 | 衡量个股是否领先于行业，领先者具有动量效应 |
| **量价背离度** | （当日涨幅排名百分位 - 当日成交量排名百分位）的绝对值 | 价涨量缩或价跌量增都是危险信号 |
| **波动率收敛度** | 近5日波动率 / 近20日波动率 | 波动率从收敛转向扩张的拐点，往往伴随趋势启动 |
| **距前高距离** | (前期高点 - 当前价) / 前期高点 | 接近前高有压力，远离前高有修复空间 |
| **分时均价偏离** | 当日收盘价 / 当日VWAP - 1 | 收盘价高于VWAP说明尾盘资金积极，正面信号 |

#### 2.3.3 换手率因子的正确实现

原方案中换手率因子直接给了默认分（`score += 5`），等于没有这个因子。

**正确实现思路：** 需要获取股票的自由流通股本数据（来源：Wind、同花顺iFind、或 AKShare 的个股信息接口），然后计算真实换手率 = 当日成交量 / 自由流通股本。适宜的换手率区间为 3%~15%，过低说明流动性不足（难以买卖），过高说明筹码过度松动（不利于后续上涨）。

### 2.4 因子权重的数据驱动确定

原方案中因子权重（净买入25%、席位35%、技术面30%、低位10%）完全是主观设定的。

**改进方案：使用 IC 加权法。**

**步骤如下：**

1. 对每个因子，计算其过去 N 个月（建议 N=6）内每天的 IC 值（信息系数），即因子值与 T+1 收益率的截面 Rank 相关系数。
2. 计算每个因子的 IC 均值和 IC_IR（= IC均值 / IC标准差）。
3. 以 IC_IR 的绝对值作为因子权重的基础，进行归一化。
4. IC 均值为负的因子需要反向使用（即因子值越大，预期收益越低）。
5. 每月滚动更新一次权重。

**伪代码提示：**
```
for each factor:
    ic_series = rolling_rank_corr(factor_values, next_day_returns, window=120days)
    ic_mean = mean(ic_series)
    ic_ir = ic_mean / std(ic_series)
    weight[factor] = abs(ic_ir)

weights = normalize(weights)  # 归一化使权重之和为1
```

IC_IR 低于 0.3 的因子建议直接剔除，保留对预测真正有贡献的因子。

## 第三部分：过拟合防控

### 3.1 Walk-Forward 滚动回测

**问题回顾：** 原方案在全部历史数据上搜索最优参数（止盈止损、持有天数等），然后在同一批数据上报告回测结果，这种做法极易过拟合。

**改进方案：滚动窗口训练-测试法。**

**具体设计：**

- 训练窗口：6 个月（用于学习因子权重和止盈止损参数）。
- 测试窗口：1 个月（用该月数据验证策略表现，不允许回看修改参数）。
- 滑动步长：1 个月。

**操作流程示意：**

```
第1轮：用 2023-01 ~ 2023-06 训练 → 在 2023-07 测试
第2轮：用 2023-02 ~ 2023-07 训练 → 在 2023-08 测试
第3轮：用 2023-03 ~ 2023-08 训练 → 在 2023-09 测试
...以此类推
```

最终报告的策略表现，仅使用所有测试窗口的收益率拼接而成，不使用任何训练窗口的数据。这样得出的结果才是策略真实的样本外表现。

### 3.2 参数敏感性分析

止盈止损参数、选股阈值等关键参数，在最优值附近应做敏感性测试。如果参数从 -5% 止损变为 -4% 或 -6% 后，策略表现急剧变化，说明策略对参数过度敏感，实盘中大概率不稳定。

**建议评估维度：**

| 参数 | 测试范围 | 合格标准 |
|------|----------|---------|
| 止损线 | -3% ~ -8%，步长1% | 最优值±2%范围内，胜率波动不超过3个百分点 |
| 止盈线 | +5% ~ +15%，步长2% | 最优值±3%范围内，平均收益波动不超过0.5% |
| 净买入阈值 | 3000万 ~ 1亿，步长1000万 | 不同阈值下胜率排名一致 |
| Top N 选股数量 | 1 ~ 5 | 收益随 N 单调变化或平稳，无跳跃 |

如果在某个参数上出现"锐利的山峰"（仅在极窄范围内表现好），该参数的设定大概率是过拟合的产物。

### 3.3 蒙特卡洛排列检验

除了 t 检验外，建议做排列检验（Permutation Test）来验证策略收益是否源于真实的预测能力。

**方法：** 将每天的选股结果随机打乱（即随机从当天的龙虎榜股票中选取同样数量的股票），重复 10,000 次，构建"随机选股"的收益率分布。如果实际策略的收益率位于随机分布的前 5%（即 p < 0.05），才可认为策略的选股逻辑是有效的。

## 第四部分：风控体系完善

### 4.1 多层风控框架

风控应分为四个层次，从个股到组合到策略到账户，层层设卡。

**第一层：个股层面风控**

| 风控规则 | 参数 | 说明 |
|---------|------|------|
| 单只止损 | -5% | 盘中触及即执行，不犹豫 |
| 单只止盈 | 分档：+5%卖半仓，+8%~10%清仓 | 分批止盈锁定利润 |
| 最大持有期 | 3个交易日 | 超期未触及止盈止损，收盘无条件清仓 |
| 涨停封板不卖 | 如果 T+1 封涨停且未打开 | 继续持有至 T+2 |
| 跌停无法卖出 | 挂跌停价排队 | 次日开盘继续卖出 |

**第二层：组合层面风控**

| 风控规则 | 参数 | 说明 |
|---------|------|------|
| 单只最大仓位 | 不超过总资金的 25% | 避免单只股票风险过大 |
| 同行业最大暴露 | 不超过总资金的 40% | 避免行业集中风险 |
| 每日最多持仓 | 3~4 只 | 分散但不过度分散 |
| 同日买入上限 | 2~3 只 | 控制单日入场节奏 |
| 现金保留底线 | 至少保留 20% 现金 | 应对极端行情和加仓机会 |

**第三层：策略层面风控**

| 风控规则 | 参数 | 说明 |
|---------|------|------|
| 单日最大亏损 | -3% 总资金 | 触发后当日停止所有新开仓 |
| 连续亏损熔断 | 连亏 3 天 | 强制休息 1 个交易日 |
| 周亏损熔断 | 单周亏损 > 5% | 该周剩余交易日停止操作 |
| 月度回撤熔断 | 月内回撤 > 8% | 该月剩余交易日停止操作，进入反思期 |
| 策略失效检测 | 连续 2 个月胜率 < 45% | 暂停策略，重新评估因子有效性 |

**第四层：账户层面风控**

| 风控规则 | 参数 | 说明 |
|---------|------|------|
| 最大回撤熔断 | 从峰值回撤 > 15% | 全部清仓，停止策略至少 1 个月 |
| 年度亏损上限 | 年内总亏损 > 20% | 当年停止交易，年底重新评估 |

### 4.2 仓位管理模型

原方案只有"满仓"和"半仓"两档，过于粗糙。

**改进方案：基于凯利公式的动态仓位。**

对每只入选股票，根据其综合评分和历史统计数据计算建议仓位：

```
f* = (p × b - q) / b

其中：
  p = 该评分区间的历史胜率
  b = 该评分区间的历史盈亏比（平均盈利 / 平均亏损的绝对值）
  q = 1 - p
  f* = 建议仓位比例（占可用资金）
```

由于凯利公式容易给出过大的仓位（尤其在历史胜率偏高时），实际使用时取**半凯利**（f*/2）作为仓位上限，更为稳健。

**叠加市场环境调节：**

```
实际仓位 = 半凯利仓位 × 市场环境系数

市场环境系数：
  - 牛市环境（涨停>50，大盘趋势向上）：1.0
  - 中性环境（涨停20~50）：0.7
  - 弱势环境（涨停<20，大盘趋势向下）：0.3~0.5
  - 极端恐慌（跌停>50）：0，不交易
```

### 4.3 市场环境识别的改进

原方案仅用涨跌停家数和大盘均线做简单判断，信息维度不足。

**改进后的市场环境评估指标体系：**

| 指标 | 计算方式 | 牛市阈值 | 熊市阈值 |
|------|----------|---------|---------|
| 涨跌停比 | 涨停家数 / 跌停家数 | > 3 | < 0.5 |
| 连板股数量 | 2连板及以上个股数 | > 15 | < 3 |
| 市场赚钱效应 | 当日上涨家数 / 总家数 | > 60% | < 30% |
| 大盘趋势 | 上证指数 5日均线 vs 20日均线 | 5MA > 20MA | 5MA < 20MA |
| 成交量变化 | 两市合计成交额 vs 20日均值 | > 1.2倍 | < 0.7倍 |
| 北向资金流向 | 当日北向净买入 | > 50亿 | < -80亿 |

建议将上述 6 个指标加权汇总为一个"市场温度计"分数（0~100），根据分数决定当日操作力度：

- 温度 ≥ 70：正常操作，仓位系数 1.0
- 温度 50~70：谨慎操作，仓位系数 0.6~0.8
- 温度 30~50：轻仓试探，仓位系数 0.3~0.5
- 温度 < 30：停止操作，空仓观望

## 第五部分：买入时机优化

### 5.1 集合竞价阶段的决策树

原方案给出了高开幅度与操作建议的对应关系，但过于简单。以下是改进后的决策树：

```
9:15 ~ 9:25 集合竞价阶段：

├── 一字涨停（高开 ≥ 10%且封单量大）
│   └── 无法买入，放弃该标的
│
├── 高开 > 7%
│   └── 放弃。高开太多，追涨风险极大
│
├── 高开 5% ~ 7%
│   ├── 竞价成交量 > 昨日全天的5% → 分歧大，放弃
│   └── 竞价成交量 < 昨日全天的3% → 挂单量不大，可观望前5分钟再决定
│
├── 高开 2% ~ 5%
│   ├── 竞价量逐步放大 → 正常买入，但仓位减至计划的70%
│   └── 竞价量萎缩 → 正常买入
│
├── 平开（-1% ~ +2%）
│   └── 最佳买点，按计划仓位买入
│
├── 低开 1% ~ 3%
│   ├── 大盘同步低开 → 正常买入，仓位可适度加大
│   └── 个股独立低开，大盘平稳 → 可能有利空，降低仓位至计划的50%，观察开盘后走势
│
└── 低开 > 3%
    └── 信号可能已失效，放弃或等待企稳后再介入
```

### 5.2 开盘后的分时买入策略

并非所有情况都适合在 9:30 开盘价直接买入。统计上，龙虎榜股票在 T+1 日的分时走势有几种典型模式：

**模式一：高开高走型（约占 20%）。** 开盘后一路上涨不回头。这种情况下开盘买入是正确的，但遗憾的是在开盘前很难判断是否属于这种模式。

**模式二：高开低走型（约占 35%）。** 开盘后冲高回落。这种情况下开盘买入会买在高点附近，损失较大。

**模式三：低开高走型（约占 20%）。** 开盘后震荡走高。这种情况下开盘买入是最优的。

**模式四：震荡无方向型（约占 25%）。** 全天窄幅波动，无明显趋势。

**建议策略：二次确认法。**

不在 9:30 盲目买入，而是观察前 15 分钟走势：

- 如果前 15 分钟股价始终在开盘价之上运行，且成交量温和放大 → 在 9:45 之前买入。
- 如果前 15 分钟出现明显回落（跌破开盘价 1% 以上） → 等待回落企稳后再买入（以分时均线企稳为信号）。
- 如果前 30 分钟无法企稳且持续走弱 → 放弃该标的。

**代价：** 这种方法会错过模式一（高开高走型），但能有效避开模式二（高开低走型），总体期望收益更优。

## 第六部分：另类数据源增强

### 6.1 融资融券数据

**数据内容：** 每日融资买入额、融资余额变化、融券卖出量。

**使用方式：**

- 融资余额连续 3 日增加 + 龙虎榜净买入 → 多重资金信号共振，加分。
- 融券余额突然大增 → 有人在做空该股票，警惕信号，减分。

### 6.2 大宗交易数据

**数据内容：** 盘后大宗交易的成交价、折溢价率、买卖方营业部。

**使用方式：**

- 龙虎榜净买入的同一天或前一天，大宗交易出现溢价成交（成交价 > 收盘价） → 强烈看多信号。
- 大宗交易大幅折价（折价 > 5%）→ 大股东或机构在低价抛售，负面信号。

### 6.3 股东人数变化

**数据内容：** 上市公司定期公布的股东户数。

**使用方式：**

- 最近一期股东户数较前一期减少 10% 以上 → 筹码集中，有利于股价上涨。
- 股东户数大幅增加 → 筹码分散，不利。

这个因子的更新频率较低（通常按季度或半年度），适合作为中低频的辅助过滤条件，而非日频信号。

### 6.4 行业/概念板块热度

**数据内容：** 同一板块中当日有多少只股票出现在龙虎榜上。

**使用方式：**

- 同板块 ≥ 3 只股票同时上龙虎榜且均为净买入 → 板块效应启动，板块内的龙虎榜股票后续表现通常更好。
- 孤立的个股上榜（同板块无其他股票上榜） → 个股行为，风险更高。

## 第七部分：机器学习替代手工打分（进阶方案）

### 7.1 模型选型

当因子数量超过 10 个时，手工设定权重已经不现实。建议引入 LightGBM 梯度提升树模型，原因如下：

- 天然处理非线性关系和因子交互效应。
- 对缺失值鲁棒，无需复杂的数据预处理。
- 训练速度快，适合日频更新。
- 内置特征重要性排序，便于理解模型在依赖哪些因子。

### 7.2 标签定义

预测目标（标签）定义为：T+1 开盘买入后，持有 1~3 天内的最大收益率是否超过交易成本（0.3%）。超过为正样本（1），否则为负样本（0）。这是一个二分类问题。

也可以将标签定义为 T+1 日收益率本身（回归问题），然后选取预测收益最高的 Top N 只。

### 7.3 特征工程

将前述所有因子（净买入强度、席位得分、技术面因子、市场环境因子、另类数据因子）统一作为模型输入特征。额外可添加的衍生特征包括：

- 因子的时序变化量（如"今天净买入强度 - 上次上榜时的净买入强度"）。
- 因子的截面排名百分位（相对于当天所有龙虎榜股票的排名）。
- 交互特征（如"机构买入 × 技术面高分"的乘积）。

### 7.4 训练与验证流程

**严格禁止在全量数据上训练后在同一数据上评估。** 必须采用以下流程：

1. 将数据按时间排序，前 70% 作为训练集，后 30% 作为测试集（不做随机分割，必须按时间顺序）。
2. 在训练集上使用 5 折时序交叉验证（TimeSeriesSplit）调优超参数。
3. 最终模型在测试集上评估，只允许一次评估机会。
4. 实盘部署后，每月用最近 6 个月数据重新训练模型。

### 7.5 模型监控与衰退检测

机器学习模型在金融领域会随时间衰退（因为市场结构在变化）。需要建立持续监控机制：

- 每周计算模型预测概率与实际结果的 AUC，若连续 4 周 AUC 低于 0.55，触发模型重训练。
- 跟踪特征重要性的变化。如果某个曾经重要的特征（如机构席位因子）的重要性大幅下降，可能意味着市场行为模式发生了变化。

| 场景 | 原方案问题 | 改进方案 |
|------|-----------|---------|

### 8.2 数据持久化存储

所有数据和交易记录必须持久化存储，建议使用 SQLite（轻量级）或 MySQL（多用户协作）。

**需要存储的数据表：**

| 表名 | 内容 | 更新频率 |
|------|------|---------|
| `lhb_daily` | 每日龙虎榜原始数据 | 日频 |
| `dept_performance` | 营业部历史表现统计 | 月频更新 |
| `stock_signals` | 每日选股信号及因子得分 | 日频 |
| `trade_log` | 实际交易记录（买卖价格、滑点、成本） | 每笔交易 |
| `daily_pnl` | 每日盈亏汇总 | 日频 |
| `market_sentiment` | 每日市场环境指标 | 日频 |
| `model_monitor` | 模型性能跟踪（AUC、IC等） | 周频 |

### 8.3 券商交易接口对接

实盘交易需要对接券商提供的程序化交易接口。目前 A 股常用方案如下：

| 方案 | 适用场景 | 备注 |
|------|---------|------|
| QMT（迅投） | 个人投资者，多数券商支持 | 需开通量化交易权限 |
| PTrade（恒生） | 机构或高净值客户 | 功能强大但门槛较高 |
| miniQMT | QMT的轻量版，支持 Python 外部调用 | 灵活性较好 |
| 券商自有API | 部分互联网券商提供REST API | 需具体咨询券商 |

**对接要点：**

- 下单前必须做价格合理性检查（防止报价错误）。
- 所有下单操作必须有本地日志记录。
- 实现"影子交易"模式——策略发出信号后，先在模拟账户执行一周，确认无Bug后再切换到真实账户。

### 8.4 监控与告警

**告警级别设计：**

| 级别 | 触发条件 | 通知方式 |
|------|---------|---------|
| INFO | 选股完成、交易执行成功 | 微信/钉钉推送 |
| WARNING | 数据获取部分失败、某笔交易滑点过大（>0.5%）、市场环境进入弱势区 | 微信/钉钉推送 + 邮件 |
| CRITICAL | 止损触发、日亏损超阈值、数据源完全失效、程序异常退出 | 电话告警 + 微信 + 邮件 |
| EMERGENCY | 最大回撤熔断触发、账户异常 | 立即清仓 + 电话告警 |

### 8.5 日志与复盘体系

每笔交易必须记录以下完整信息，用于事后归因分析：

- 选股决策依据：上榜日期、净买入额、席位详情、技术面得分、综合评分排名。
- 执行细节：计划买入价 vs 实际买入价（滑点）、计划仓位 vs 实际仓位。
- 退出细节：退出原因（止盈/止损/到期）、计划卖出价 vs 实际卖出价。
- 市场环境：买入当天的市场温度计分数、大盘涨跌、行业涨跌。

每周复盘时，至少分析以下问题：

1. 本周亏损最大的 3 笔交易，亏损原因是什么？能否通过改进因子避免？
2. 本周最赚钱的 3 笔交易，盈利的核心驱动力是什么？是因子选股的功劳还是运气？
3. 有没有符合条件但被过滤掉的好股票？过滤条件是否过严？
4. 策略的实际表现与回测预期偏差多大？偏差原因是什么？

## 第十部分：预期效果与风险提示

### 10.1 改进后的预期表现范围

| 指标 | 原方案估计 | 改进后保守估计 | 说明 |
|------|-----------|--------------|------|
| 胜率 | 58%~65% | 52%~58% | 扣除交易成本和过拟合后胜率会下降 |
| 平均单笔净收益 | 1.5%~3.0% | 0.5%~1.5% | 扣除成本后的真实收益 |
| 盈亏比 | 1.5~2.5 | 1.3~2.0 | 止盈止损参数调优后的合理范围 |
| 月均净收益 | 5%~12% | 2%~5% | 考虑仓位管理和空仓日后 |
| 最大回撤 | 未评估 | 8%~15% | 需严格执行风控规则 |

请注意，原方案给出的预期表现（月均5%~12%）很可能显著偏高，这是因为没有扣除交易成本、存在未来信息泄露、且参数在样本内优化导致过拟合。改进后的保守估计更接近实际可达到的水平。

### 10.2 关键风险提示

1. **策略容量有限。** 龙虎榜策略的参与者众多，随着资金规模增大，买入时的冲击成本和滑点会急剧增加。本策略适合的资金规模上限约为 200~500 万元人民币。超过此规模需要考虑分散到多个策略中。

2. **监管政策风险。** 如果交易所修改龙虎榜的公布规则（如延迟公布、减少公布频率、或取消营业部信息），策略将失去数据基础。

3. **市场结构变化。** 过去有效的因子（如机构席位跟踪）可能因为市场参与者结构变化而失效。必须持续监控因子的 IC 值变化。

4. **T+1 制度限制。** A 股 T+1 交易制度使得买入当天无法卖出，如果 T+1 日开盘即大幅低开，无法止损。这是该策略的系统性风险。

5. **这不是"稳赚"的策略。** 任何声称月均收益 5%~12% 且几乎无风险的策略都应被高度怀疑。量化投资的本质是在概率上获取微小的统计优势，然后通过大量交易累积收益。亏损是不可避免的，关键是控制亏损幅度并确保长期期望为正。
