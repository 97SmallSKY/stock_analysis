# 复盘总结系统增强设计方案

---

## 一、当前系统的能力边界分析

```
当前已有的:
  ✅ 亏损自动归因(四维: 卖出类型/信号质量/技术面/选股方式)
  ✅ 双写持久化(DB + Markdown)
  ✅ LLM闭环消费(教训注入选股prompt)
  ✅ 幂等写入 + 异常不阻断主流程
  
当前缺失的(你提出的核心问题):
  ❌ 平仓后不再跟踪 — 卖了就不管了，不知道卖早了还是卖晚了
  ❌ 没有"最优卖点"回溯分析 — 不知道理论上最佳卖出时机在哪
  ❌ 没有技术面事后验证 — 买入时的技术判断对不对，无从考证
  ❌ 没有"如果持有到现在"的对比 — 缺少反事实分析
  ❌ 教训只有定性描述 — "下次注意大盘情绪"太模糊，没有量化
```

## 二、平仓后跟踪系统设计

### 2.1 核心思路

```
每笔交易平仓后，不是"结束"，而是进入"观察期":

  买入 → 持有 → 平仓 → 观察期(1周+3周) → 最终复盘
  
  观察期要回答3个核心问题:
  ① 卖早了还是卖晚了？(最优卖点在哪)
  ② 买入逻辑对不对？(后续走势验证)
  ③ 下次同类情况该怎么做？(可执行的改进)
```

### 2.2 观察期数据采集

```
平仓后自动采集的数据点:

时间轴:
  T+0:  平仓日(已有)
  T+1:  平仓后第1天
  T+3:  平仓后第3天
  T+5:  平仓后第5天(1周)
  T+10: 平仓后第10天(2周)
  T+15: 平仓后第15天(3周)

每个时间点采集:
  · 收盘价 / 最高价 / 最低价
  · 相对平仓价的涨跌幅
  · 相对买入价的涨跌幅
  · 成交量(相对5日均量的倍数)
  · 所在板块当日涨跌幅
  · 大盘当日涨跌幅

存储位置:
  新增表 sim_trade_post_tracking
  字段: trade_id / track_date / track_day(T+N)
        close / high / low / volume_ratio
        pct_vs_sell / pct_vs_buy
        sector_pct / index_pct
```

### 2.3 关键分析维度

#### 维度一：最优卖点回溯

```
在观察期内找到"理论最优卖点":

计算方法:
  从买入日到T+15的完整K线中
  找到使收益最大化的卖出日

分析输出:
  "该笔交易:
   实际卖出: T+2, 价格23.50, 收益-8.9%
   最优卖点: T+1开盘后30分钟, 价格26.80, 理论收益+3.9%
   差距: 12.8个百分点
   
   最优卖点的技术特征:
   · 当天放量冲高(量比2.3)但未封涨停
   · RSI达到78(超买)
   · 触及布林带上轨
   
   教训: 该股在T+1冲高时出现明显的获利了结信号
         如果当时有'冲高量价背离减仓'规则，可避免亏损"
```

#### 维度二：卖出决策验证

```
回答: "卖的时机对不对"

场景A: 卖早了(平仓后继续涨)
  T+5涨幅 > +5% → 标记"卖早"
  分析: 
  · 为什么涨？(板块持续热/主力继续买/利好催化)
  · 什么信号能让系统不那么早卖？
  · 是止损标准太紧？还是止盈目标太低？
  
场景B: 卖对了(平仓后继续跌或横盘)
  T+5涨幅 < +2% → 标记"卖出正确"
  分析:
  · 确认止损/止盈逻辑有效
  · 记录为"正面教训"(系统做对了)

场景C: 卖晚了(平仓前有更好的卖点)
  持有期间最高价 > 平仓价 + 3% → 标记"卖晚"
  分析:
  · 最高点在哪天？当天有什么信号？
  · 移动止盈是否应该更灵敏？
  · 是否因为止盈档位设置不合理？
```

#### 维度三：买入逻辑事后验证

```
回答: "买入的理由事后看对不对"

对比买入时的判断 vs 实际走势:

  买入理由: "机构净买3000万，板块处于启动期"
  实际情况: 
  · 机构次日即出现在卖方(一日游) → 买入理由被证伪
  · 板块第3天见顶回落 → 板块判断时机偏晚
  
  结论: 这不是随机亏损，而是信号质量问题
  量化改进: 
  · 标记该机构席位为"一日游高概率"(降低评分权重)
  · 板块已连涨2天时降低新建仓评分

对比项清单:
  □ 龙虎榜席位后续动向(次日是否出现在卖方)
  □ 板块后续走势(继续涨/见顶/回调)
  □ 大盘后续走势(是否系统性变化)
  □ 该股后续是否再次上龙虎榜
  □ 买入时的技术指标后续验证(RSI/MACD/均线)
```

#### 维度四：持有期间的关键时刻回放

```
回答: "持有过程中有没有错过应该行动的时刻"

在持有期K线上标注关键事件:

  Day1(买入): 评分65, 机构净买2000万
  Day2: ⚠️ 放量冲高回落(量比2.5, 上影线>3%)
        → 回顾: 这里应该减仓(冲高回落是短期见顶信号)
        → 系统当时: 没有盘中分时监控，错过了
  Day3: 缩量下跌(量比0.6, 跌-3.2%)
        → 回顾: 缩量下跌不可怕，但前一天冲高回落+今天继续跌=趋势转弱
        → 系统当时: 只看了收盘价，没有综合前一天的信号
  Day4: 止损触发(-5%), 卖出

  关键遗漏: Day2的"放量冲高回落"是最重要的卖出信号
            如果Day2减仓50%，整体亏损从-5%降到-2.5%
```

## 三、反事实分析模块

### 3.1 "如果不卖会怎样"

```
每笔平仓交易，自动计算"反事实收益":

  实际操作: T+2止损卖出, 收益-5.2%
  
  反事实1: 如果持有到T+5 → 收益会是-8.1%(卖对了，少亏了3%)
  反事实2: 如果持有到T+10 → 收益会是+2.3%(卖错了，本来能翻正)
  反事实3: 如果T+1冲高时卖 → 收益会是+3.8%(最优解)

输出:
  "本笔交易止损决策评估:
   短期(5天)验证: ✅ 止损正确(继续跌了3%)
   中期(10天)验证: ❌ 止损过早(10天后翻正)
   最优操作: T+1冲高减仓(可赚3.8%)
   
   综合判断: 止损本身没错(不能事后诸葛亮)
             但如果有T+1冲高减仓机制，可以避免止损"
```

### 3.2 "如果用不同参数会怎样"

```
每笔交易回溯检验不同参数的效果:

  参数A(当前): 止损-5%, 止盈+8%
    实际结果: -5.2%
    
  参数B(宽止损): 止损-8%, 止盈+8%
    模拟结果: 不会触发止损, 持有到T+5结果-8.1%(更差)
    
  参数C(紧止损): 止损-3%, 止盈+5%
    模拟结果: T+1就止损, 结果-3%(少亏2%)
    
  参数D(移动止盈): 止损-5%, 从高点回落3%止盈
    模拟结果: T+1冲高后回落3%触发止盈, 结果+0.8%(最优)

结论:
  "当前参数(A)在本笔交易中表现中等
   参数D(移动止盈)表现最优
   但需要更多样本验证参数D的整体效果
   建议: 将参数D加入影子模式跟踪"
```

## 四、技术面事后复盘

### 4.1 买入时技术指标的准确性验证

```
买入时记录的技术判断 vs 实际走势:

  买入时判断: "MACD金叉, RSI=55(中性), 站上MA5"
  
  事后验证:
  · MACD金叉: 
    金叉后3天内继续上涨? → 否, 第2天就死叉
    判断: MACD金叉在该股近期的可靠性低
    统计: 该股最近10次MACD金叉, 3天内继续涨的只有4次(40%)
    
  · RSI=55:
    后续RSI走势: 55→72(T+1)→45(T+3)
    判断: RSI快速冲高后回落, 典型的"假突破"
    
  · 站上MA5:
    后续: T+2跌破MA5, T+3跌破MA10
    判断: 均线支撑不可靠, 该股短期均线频繁穿越

  综合评估:
  "买入时的3个技术信号中:
   MACD金叉 — 失败(该股MACD金叉可靠性仅40%)
   RSI中性  — 部分正确(但未预料到次日冲高)
   MA5支撑  — 失败(2天后即跌破)
   
   技术面评分调整建议:
   该类小盘科技股的MACD权重应降低
   更可靠的信号是: 缩量回踩MA20后放量突破"
```

### 4.2 形态学复盘

```
平仓后用完整K线回看, 识别买入时未发现的形态:

  回顾发现:
  "买入前3天形成了'黄昏之星'顶部反转形态
   Day-3: 大阳线(涨停)
   Day-2: 十字星(多空分歧)
   Day-1: 大阴线(空方胜出)
   Day-0: 我们在这里买入 ← 实际上是顶部反转后的第一天!
   
   错误: 龙虎榜数据显示机构在Day-3买入(涨停日)
         但黄昏之星暗示短期见顶
         龙虎榜信号与技术形态矛盾时, 应谨慎"

  建议:
  "在评分模型中增加K线形态因子:
   出现顶部反转形态(黄昏之星/乌云盖顶/吞没)时
   评分扣10-15分"
```

## 六、跟踪数据驱动的自动改进

### 6.1 从跟踪数据中自动提取改进建议

```
不只是"看看卖出后涨了还是跌了"
而是从跟踪数据中自动发现可执行的模式:

模式发现1: 最优持有天数
  "统计最近100笔交易的最优卖点分布:
   T+1: 35笔(35%)的最优卖点在第1天
   T+2: 28笔(28%)
   T+3: 18笔(18%)
   T+4: 10笔(10%)
   T+5+: 9笔(9%)
   
   结论: 63%的最优卖点在前2天
   当前系统: 默认持有T+2
   建议: T+1如果已盈利>3%, 应该卖出至少50%(不要等T+2)"

模式发现2: 止损后反弹的特征
  "统计止损后T+5反弹>5%的交易(共15笔):
   共同特征:
   · 12笔(80%)止损当天成交量<5日均量(缩量止损)
   · 10笔(67%)所在板块当天是上涨的(个股逆板块下跌)
   · 9笔(60%)止损前一天是放量上涨的(洗盘特征)
   
   结论: '缩量止损+板块上涨+前日放量'是典型的洗盘止损
   建议: 满足这3个条件时, 止损只减仓50%, 保留50%观察T+1"

模式发现3: 卖出信号缺失
  "统计所有'卖晚了'的交易(持有期有更好卖点):
   最优卖点当天的共同技术特征:
   · 85%出现了'量价背离'(价涨量缩或价平量增)
   · 72%当天RSI>70
   · 65%触及了布林带上轨
   · 58%出现了长上影线(>2%)
   
   结论: 量价背离是最可靠的卖出信号(85%准确率)
   建议: 在盘中监控中增加量价背离检测, 触发时自动减仓30%"
```

### 6.2 跟踪数据与教训库的交叉验证

```
用跟踪数据验证教训的有效性:

教训L-0028: "放量下跌应及时止损"
  验证: 找出所有"放量下跌但没止损"的交易
        T+5后的平均走势: 继续跌-4.2%
        结论: 教训有效 ✅

教训L-0042: "板块高潮期不建仓"
  验证: 找出所有"板块高潮期建仓"的交易
        T+15后的平均走势: -6.8%
        对比"板块启动期建仓": T+15后平均+4.2%
        结论: 教训有效, 且差距巨大(11个百分点) ✅
```

### 8.6 飞书消息的技术实现要点

```
消息类型选择:

  日常速报(板块1/2/3): 
    → 飞书"富文本消息"(post类型)
    → 支持标题+多段落+加粗+链接
    → 适合中等长度的结构化信息
    → 字数限制: 约4000字, 日常速报足够

  周度报告:
    → 飞书"交互式卡片"(interactive类型)
    → 支持折叠展开(深度分析可折叠)
    → 支持按钮(如"查看完整遗珠分析")
    → 适合信息量大但需要层次感的报告

  月度大屏:
    → 飞书"云文档"链接 + 摘要卡片
    → 完整报告生成为飞书文档(支持表格/图表)
    → 飞书群里推送摘要卡片+文档链接
    → 适合超长报告, 不受消息长度限制

推送频率控制:
  
  盘中事件提醒:
    → 同一只股票同类事件30分钟内不重复推送
    → 每小时最多推送5条(防刷屏)
    → 重大事件(大基金增持/监管处罚)不受限制
  
  盘后速报:
    → 每日最多3条消息(跟踪速报+对比速报+事件汇总)
    → 无新数据时不推送(不发空报告)
    → 周五合并为周报, 不单独发日报

  静默时段:
    → 22:00-08:00不推送(除非紧急事件)
    → 周末只推送周报(周六上午10点)
```
