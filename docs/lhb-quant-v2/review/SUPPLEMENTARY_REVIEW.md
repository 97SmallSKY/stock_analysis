## 二、数学与统计层面

### 2.1 评分因子相关性风险

| 问题 | 关注点 | 状态 |
|------|--------|------|
| 技术面/资金面/历史面因子可能高度相关 | 上线前做皮尔逊相关系数矩阵分析 | 待实现 |
| 重复计分风险 | 高度相关因子需去冗余或正交化 | 待实现 |
| 权重分配依据 | 需历史数据回归验证，不能拍脑袋 | 待实现 |

### 2.2 过拟合风险

| 问题 | 关注点 | 状态 |
|------|--------|------|
| 策略参数通过历史回测调优 | 回测数据划分训练集/测试集 | 待实现 |
| 参数敏感性未知 | 止损 -5% 改为 -4%/-6% 结果变化多大 | 待分析 |
| 无稳健性机制 | 需参数平滑、正则化、蒙特卡洛模拟 | 待实现 |

### 2.3 胜率与赔率

| 问题 | 关注点 | 状态 |
|------|--------|------|
| 只关注胜率忽略赔率 | 期望收益 = 胜率×盈利 - 败率×亏损 | 待实现 |
| 止盈3% vs 止损5% | 赔率 < 1:1，需重新评估 | 待调整 |
| Kelly公式仓位管理 | 考虑纳入 | 待评估 |

### 2.4 Sharpe Ratio 计算细节

| 问题 | 关注点 | 状态 |

| 年化因子 | 日频√252，周频√52 | 待定义 |
