### 1.4 hold_days 精确定义（唯一真相源）

> 本定义作为 hold_days 计算的唯一定义来源，其他文档应引用本节。

```yaml
## 计算规则

### 基础规则
1. 使用交易日计算（非自然日）
2. 买入当天 = 第0天（不计入）
3. T+1 = 第1天
4. 停牌日不计入（冻结计数）

### 计算公式
hold_days = count_trading_days(buy_date, current_date) 
            - count_suspended_days(stock_code, buy_date, current_date)

### 到期判定
is_expired = hold_days >= max_hold_days

### 到期卖出时机
- 到期当日开盘后即可卖出
- 盘中监控在 09:35 首次检查时触发到期卖出
- 不等到14:55（给足够时间成交）

### 正常示例
buy_date = 周一（T+0）
max_hold_days = 3

周一（T+0）：hold_days=0，持有
周二（T+1）：hold_days=1，持有
周三（T+2）：hold_days=2，持有
周四（T+3）：hold_days=3，到期 → 09:35后卖出

### 停牌示例
buy_date = 周一（T+0）
max_hold_days = 3
周三停牌

周一（T+0）：hold_days=0，持有
周二（T+1）：hold_days=1，持有
周三（停牌）：hold_days=1，冻结（不计入）
周四（T+2）：hold_days=2，持有
周五（T+3）：hold_days=3，到期 → 09:35后卖出
```

## 四、盘中监控流程（10秒轮询）

### 4.1 触发条件

- 时间: 有效监控时段内（见下）
- 触发方式: Celery Beat 每10秒触发
- 执行方式: 独立队列（monitor），防止被阻塞

### 4.2 有效监控时段

```python
def is_monitor_active() -> bool:
    """
    监控时段判断（精确版）
    
    排除：
    - 开盘集合竞价结果公布期 (09:25-09:30)
    - Phase B 执行期 (09:30-09:35)
    - 午间休市 (11:30-13:00)
    - 收盘集合竞价期 (14:57-15:00)
    """
    now = datetime.now().time()
    
    # 上午连续竞价（不含开盘和收盘）
    morning = time(9, 35) <= now <= time(11, 30)
    
    # 下午连续竞价（不含开盘和收盘）
    afternoon = time(13, 0) <= now <= time(14, 57)
    
    return morning or afternoon
```

| 时段 | 状态 | 说明 |
|------|------|------|
| 09:30-09:35 | ❌ 暂停 | Phase B 执行期间 |
| 09:35-11:30 | ✅ 监控 | 上午连续竞价 |
| 11:30-13:00 | ❌ 暂停 | 午间休市 |
| 13:00-14:57 | ✅ 监控 | 下午连续竞价 |
| 14:57-15:00 | ❌ 暂停 | 收盘集合竞价 |

### 5.2 流程步骤

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 到期持仓确认（兜底）                                 │
├─────────────────────────────────────────────────────────────┤
│ 查询: status IN ('open', 'partial')                        │
│       AND buy_date IS NOT NULL                             │
│ 过滤: hold_days >= max_hold_days                          │
│                                                             │
│ 如果存在到期未卖出的持仓：                                  │
│   → 以收盘价记账（模拟盘）                                 │
│   → 标记 sell_reason = 'expire_forced'                    │
│   → 发送告警（盘中监控应该已处理，此处是兜底）            │
│                                                             │
│ 注意：不应使用 signal_date = 今日 作为过滤条件             │
│       （这会错误地强制平仓当日买入的股票）                 │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 2: 计算净值                                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ ## 持仓市值计算                                             │
│ position_value = SUM(                                       │
│     remaining_shares × close_price                         │
│     FOR EACH trade WHERE status IN ('open', 'partial')     │
│ )                                                           │
│                                                             │
│ ## remaining_shares 计算                                    │
│ remaining_shares = buy_shares                               │
│     - SUM(sell_shares FROM trade_executions                 │
│             WHERE execution_type != 'buy')                  │
│                                                             │
│ ## 总资产                                                    │
│ total_assets = robots.cash_balance + position_value        │
│                                                             │
│ ## 净值比                                                    │
│ nav_ratio = total_assets / robots.initial_capital          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 3: 今日盈亏计算                                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ ## 获取昨日净值                                              │
│ prev_nav = (                                                │
│     SELECT close_nav FROM daily_nav                        │
│     WHERE robot_id = :id AND nav_date < :today             │
│     ORDER BY nav_date DESC LIMIT 1                         │
│ )                                                           │
│                                                             │
│ ## 首日特殊处理                                              │
│ IF prev_nav IS NULL:                                        │
│     prev_nav = robots.initial_capital                      │
│                                                             │
│ ## 今日盈亏                                                  │
│ daily_pnl = total_assets - COALESCE(prev_nav, initial_capital)
│ daily_pnl_ratio = daily_pnl / COALESCE(prev_nav, initial_capital)
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 4: 最大回撤计算                                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ ## 历史最高净值（全历史）                                    │
│ historical_max = MAX(close_nav) FROM daily_nav             │
│                  WHERE robot_id = :id                       │
│                                                             │
│ ## 当前回撤                                                  │
│ current_drawdown = (historical_max - total_assets) / historical_max
│                                                             │
│ ## 最大回撤更新                                              │
│ max_drawdown = MAX(所有历史 drawdown 值)                    │
│                                                             │
│ ## 首日特殊处理                                              │
│ IF historical_max IS NULL:                                  │
│     max_drawdown = 0 (如果盈利)                             │
│     max_drawdown = -daily_pnl_ratio (如果亏损)              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 5: 写入净值曲线                                         │
├─────────────────────────────────────────────────────────────┤
│ 写入: daily_nav 表                                          │
│ 字段:                                                       │
│   - robot_id                                                │
│   - nav_date = 今日                                         │
│   - total_nav = total_assets                               │
│   - nav_ratio                                               │
│   - cash = robots.cash_balance                             │
│   - position_value                                          │
│   - daily_pnl                                               │
│   - daily_pnl_ratio                                        │
│   - drawdown = current_drawdown                            │
│   - max_drawdown                                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 6: 生成日终报告                                         │
├─────────────────────────────────────────────────────────────┤
│ 模板: [日报] 📊 {机器人名} 交易日报                         │
│ 内容: 见 §十通知模板                                        │
│ 发送: 飞书 Webhook                                          │
└─────────────────────────────────────────────────────────────┘

- 前置条件: 结算已完成（daily_nav 已写入）

### 6.2 流程步骤

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 查询机器人                                          │
├─────────────────────────────────────────────────────────────┤
│ 条件: status IN ('running', 'paused')                       │

┌─────────────────────────────────────────────────────────────┐
│ Step 2: 获取近20笔交易                                      │
├─────────────────────────────────────────────────────────────┤

│ 排序: sell_date DESC                                        │
│ 限制: LIMIT 20                                              │
│                                                             │
│ 计算:                                                       │
│   - WIN_RATE = 盈利笔数 / 总笔数                            │
│   - AVG_PNL = SUM(realized_pnl_ratio) / 笔数               │
│   - CONSECUTIVE_LOSS = 从最近一笔往前数的连续亏损笔数（最多5）│

│                                                             │
│ 公式见 RISK_CONTROL.md §三 AHS 仓位管理系统                 │
│                                                             │
│ AHS_SCORE = win_penalty × 0.25                              │

│                                                             │
│ 其中：                                                      │
│   win_penalty = (1 - WIN_RATE) × 100                        │

│                                                             │
│ 冷启动处理（交易数 < 20）:                                  │
│   penalty = (1 - count/20) × 20                             │

┌─────────────────────────────────────────────────────────────┐

│ | 谨慎     | ≤ 35     | > 40     | 85%      |               │
│ | 保守     | ≤ 55     | > 60     | 70%      |               │
│ | 警戒     | ≤ 75     | > 80     | 40%      |               │

└─────────────────────────────────────────────────────────────┘

                            ▼
┌─────────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────────┤

```python
async def check_phase_b_completion(trade_date: date) -> None:
    """检查 Phase B 是否完成"""
    # 获取昨日 pending 交易
    prev_day = prev_trading_day(trade_date)
    pending_count = await count_trades(
        status='pending',
        signal_date=prev_day
    )
    
    if pending_count > 0:
        # 检查今日是否有 Phase B 执行记录
        phase_b_executed = await check_trade_events(
            event_type='phase_b',
            event_date=trade_date
        )
        
        if not phase_b_executed:
            logger.warning(f"Phase B 未执行，触发补偿: {trade_date}")
            await run_phase_b.delay(trade_date=trade_date)
            await send_alert(
                title="Phase B 补偿执行",
                message=f"检测到 Phase B 未执行，已自动补执行",
                level="WARNING"
            )
```

## 十一、状态流转图

### 11.1 交易状态流转

```
                    ┌──────────────┐
                    │   pending    │
                    │   (预买入)   │
                    └──────┬───────┘
                           │ Phase B 执行
                           │ (买入成功)
                           ▼
┌──────────────┐    ┌──────────────┐
│  abandoned   │◄───│    open     │
│   (放弃)     │    │   (持仓)    │
└──────────────┘    └──────┬───────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
      止盈1触发 │    止盈2触发 │    止盈3触发 │
      (卖300股) │    (卖300股) │    (卖全部)  │
              │            │            │
              ▼            ▼            ▼
       ┌──────────────┐    ┌──────────────┐
       │   partial    │───►│   closed     │
       │  (部分卖出)  │    │   (已结束)   │
       └──────────────┘    └──────────────┘

特殊转换（可直接到 closed）：
- 止损触发 → closed（全部剩余）
- 到期触发 → closed（全部剩余）
- 连板开板 → closed（全部剩余）
- 手动平仓 → closed（全部剩余）
```

### 11.2 机器人状态流转（含 eliminated）

```
┌────────────┐    ┌────────────┐    ┌────────────┐
│   paper    │───►│  running   │◄──►│  paused    │
│ (模拟盘)   │    │  (运行中)  │    │  (已暂停)  │
└────────────┘    └─────┬──────┘    └────────────┘
                        │                  ▲
         AHS熔断        │                  │ 手动恢复
         累计亏损       │                  │
         手动停止       │                  │
                        ▼                  │
                  ┌────────────┐          │
                  │  stopped   │──────────┘
                  │  (已停止)  │
                  └─────┬──────┘
                        │ 周五淘汰检查
                        │ (排名最后)
                        ▼
                  ┌────────────┐
                  │ eliminated  │
                  │  (已淘汰)   │
                  └─────┬───────┘
                        │
                        │ 持仓全部清空后
                        │
                        ▼
                  ┌────────────┐
                  │  ended      │
                  │ (已结束)    │
                  └─────────────┘

eliminated 状态特性：
- 不参与 Phase A 选股
- 不创建新的 pending 交易
- 现有持仓继续由盘中监控管理
- 止损止盈仍然生效
- 持仓到期仍然生效
- 持仓全部清空后，标记 ended_at

恢复路径（手动干预）：
eliminated → stopped（确认无持仓）→ running（重置观察期）
```
