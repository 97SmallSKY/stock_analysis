## 🎯 设计亮点

### 1. 三阶段采集架构
```python
async def run():
    df = await fetch()           # 1️⃣ 抓取（AKShare API）
    records = await transform()  # 2️⃣ 转换（清洗）
    count = await save()         # 3️⃣ 保存（UPSERT）
```

### 2. 自动重试 + 指数退避
```python
MAX_RETRIES = 3
RETRY_BACKOFF = [1, 3, 10]  # 秒
# 失败自动记录到 collector_error_log
```

### 3. PostgreSQL UPSERT 去重
```sql
INSERT INTO lhb_stock_daily VALUES (...)
ON CONFLICT (trade_date, stock_code)
DO UPDATE SET ...
```

### 4. 交易日智能检查
```python
import chinese_calendar as cc
is_trading = cc.is_workday(date.today())
```

### 5. 完整的错误追踪
- 日志文件（logs/）
- 数据库错误表（collector_error_log）
- 重试次数记录
- 完整的调用栈
