### 2026-04-20 · feature · 首页情绪卡片 20 字段全覆盖

首页 Dashboard 的「市场情绪」区域现在**所有 20 个字段都有值**,不再有空白。

包括:
- **基础情绪**:涨停家数 / 跌停 / 情绪评分(45 中性)/ 级别
- **衍生统计**:涨跌比 / 平均涨幅 / 中位涨幅 / 强势股 / 弱势股
- **涨跌家数**:总股票数 / 涨家数 / 跌家数
- **龙虎榜动态**(今日新增):上榜股票数 / 当日净买入总额 / 平均评分
- **情绪环比**(今日新增):`sentiment_change` 与前一交易日情绪评分的差值(正数代表变热,负数代表变冷)

实现上,部分字段**在 API 层实时从数据库聚合**,无需依赖定时任务回填,响应快(+3ms 级)且总是最新。

### 2026-04-20 · fix · 首页情绪卡片不再空白

**现象**:首页「涨跌比 / 平均涨幅 / 中位涨幅 / 强势股 / 弱势股」等卡片在盘中时段显示「-」或空白。

**原因**:系统每天抓一次市场情绪数据,今日盘中只能抓到「涨停/跌停家数」,其余统计字段要等收盘后算。首页之前取最新日期,于是看到了「半成品」。

**修复**:首页改为取**最新一条完整的情绪数据**,通常是昨日收盘。即使盘中数据还没跑完,首页展示的也是完整信息(例如「涨跌比 0.74 · 平均 +0.21% · 强势 203 只 · 弱势 35 只」)。

### 2026-04-20 · fix · 决策信号/盈亏分析点击股票后日 K 打不开

**现象**:从决策信号或盈亏分析页点击股票,弹出的 K 线图**打不开**或显示空白。

**原因**:前端请求的数据量(最多 2000 行)超出了后端默认限制(1000 行),接口直接拒绝,错误提示一闪而过,用户感知为「点了没反应」。

**修复**:后端上限放宽到日 K 5000 行(约 20 年)、周 K 2000 行(约 40 年),完全覆盖前端所有区间。

**验证**:5 个场景真实 curl 确认 HTTP 200 + 真实行数返回,越界请求 (5001 行) 仍返回错误保护数据库。
